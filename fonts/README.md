# Fonts

`Glass_TTY_VT220.ttf` is Glass TTY VT220 by Viacheslav Slavinsky, a TrueType recreation of
the DEC VT220 screen font. It is used by the control terminal at the top of the page.

- Source: https://github.com/svofski/glasstty
- Licence: the Unlicense, a public-domain dedication. The text is in `LICENSE` in this
  folder and applies to the font only, not to the rest of this repository.
